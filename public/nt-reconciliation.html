Database / Web Presentation

Database Structure

แบ่งเป็น raw staging tables สำหรับเก็บไฟล์นำเข้าตาม source, mapping tables สำหรับ normalize key, reconcile result tables สำหรับเก็บสถานะ payment และ exception tables สำหรับรายการที่ไม่ตรงหรือรอตรวจสอบ

Web Presentation

หน้าเว็บแสดง summary payment status, matched/unmatched count, exception list, filter ตามระบบ/วันที่/channel/status และ drilldown ราย transaction เพื่อให้ทีมตรวจสอบรายการผิดปกติได้เร็วขึ้น
