Architecture Layers

Frontend
Next.js UI สำหรับ incident list/detail, create/edit form, project reports, team dashboard, admin pages และ rich text/report editor
API Layer
Express REST API รองรับ authentication, authorization, request validation, pagination, filtering, status update และ report/export endpoints
Domain Logic
Incident lifecycle, severity/priority, team assignment, SLA tracking, problem analysis, corrective action และ approval/status control
Data Layer
PostgreSQL สำหรับ incidents, users, teams, projects, templates, import logs, action history และ analytics-ready summary
Document Layer
Export service สำหรับ Excel, Word, PDF, template parsing, project report และ incident/problem report package
Monitoring
Dashboard สำหรับ workload, SLA, incident trend, project status, import result, admin analytics และ operational trace

Infrastructure / Runtime

Application Runtime

Frontend ทำงานเป็น Next.js application, backend เป็น Express TypeScript API, database เป็น PostgreSQL และ report/export service ใช้ library แยกสำหรับ document generation

Operational Concerns

ระบบออกแบบให้ตรวจสอบย้อนหลังได้ผ่าน audit/import logs, รองรับ role-based access, dashboard monitoring, export consistency และการแยก domain service เพื่อลด coupling ระหว่าง incident workflow กับ document generation
